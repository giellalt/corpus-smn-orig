Pirâstiäđu kirjeh láá almostum aanaarsämikielân

Vuáđumáttááttâs kuálmád luokan uáivildum aanaarsämikielâlâš pirâstiäđu uáppee kirje já pargokirje láá almostm. Kirjeh láá Otava ´Koulun ympäristötieto´ –kirjerááiđu heiviittum jurgâlusah. Kiirjijd lii jurgâlâm Ilmari Mattus. Rááiđu niäljád luoka kirjeh láá pargo vyelni. Luuvâ lase

täst.
